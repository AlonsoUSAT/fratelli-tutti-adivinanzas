# Fratelli Tutti — Desafío de Enigmas Contrarreloj 🕊️

Juego web interactivo de adivinanzas y contrarreloj basado en la encíclica **Fratelli Tutti** de la Doctrina Social de la Iglesia, diseñado para dinámica grupal (Grupos 1, 2, 3, 5, 6, 7 y 8).

---

## 🎯 Dinámica del Juego

* **7 Preguntas de una sola palabra**: Cada grupo responde un enigma inspirado en los capítulos de la encíclica.
* **Criterio Ganador**: Menor tiempo de respuesta (cronómetro por grupo).
* **Pistas de letras**: Revela una letra con penalización de +2 segundos al reloj.
* **Podio Top 3**: Al finalizar todas las preguntas, se presenta el podio con medallas de oro, plata y bronce, además de la tabla general de posiciones.

---

## 📁 Archivos del Proyecto

* **`index.html`**: Versión principal con diseño interactivo Neón / Dark Mode, audio sintetizado (Web Audio API) y efectos de confeti.
* **`minimalista.html`**: Versión alternativa con diseño ultra-minimalista moderno (React + Tailwind CSS vía CDN, ejecutable directamente en el navegador sin compilación previa).
* **`FratelliEnigmas.jsx`**: Componente React modular listo para ser integrado en proyectos Vite o Next.js.

---

## 🚀 Cómo Ejecutarlo

No requiere instalación de dependencias ni servidores complejos:

1. Clona o descarga este repositorio:
   ```bash
   git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
   ```
2. Haz doble clic sobre **`index.html`** o **`minimalista.html`** para abrirlo en tu navegador favorito (Chrome, Edge, Firefox, Brave, Safari).
